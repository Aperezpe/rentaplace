# Sorter trial: smoke-jev-fresh

Set: fresh. 8 tickets. Keyword rules: 1 run (deterministic). Models: 1 run(s) per ticket. Haiku and Sonnet: thinking off, via Pi CLI. Jev: TypeSafe System One.

Jev rule (in code): money = moneyP >= 0.3; unsure if 0.3 <= moneyP < 0.7 or owner confidence < 0.7.
